# Game mechanics

- LP: start 8000 (configurable per game). Damage/Recover messages update it.
- Deck-out: if you must draw with an empty deck, you lose (win reason 2).
- Xyz: overlay monsters of the same level; rank = overlay units.
- Special Summon: from hand/extra/grave/deck per card text.
- Side decking (best-of-3 match): between games, swap up to 15 cards.
